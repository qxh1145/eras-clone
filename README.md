# eras-clone

Bản mirror tĩnh của [erasvietnam.vn](https://erasvietnam.vn), đăng với sự cho phép của Eras Việt Nam.

- Chạy trên máy: `python3 serve.py` → http://localhost:8000
- Bản tĩnh để deploy: `python3 build.py /eras-clone` → `dist/` (GitHub Actions tự build và deploy lên GitHub Pages mỗi lần push lên `main`)

Hạn chế: form liên hệ/đăng nhập không hoạt động; một số script/ảnh không có trong mirror vẫn được tải từ site thật.
